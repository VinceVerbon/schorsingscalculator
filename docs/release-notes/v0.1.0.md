# Camper Schorsingscalculator v0.1.0 — Initial Release

**Date**: 2026-05-04
**Live**: [https://mycamper.app/schorsing](https://mycamper.app/schorsing)

## Summary

Eerste publieke release van de Camper Schorsingscalculator. Een single-page rekentool
(één HTML-bestand, geen build, geen dependencies) die een Nederlandse camper-eigenaar
helpt bepalen of, wanneer en hoe lang het loont om bij de RDW een schorsing aan te
vragen om motorrijtuigenbelasting te besparen.

De tool is bewust offline-bruikbaar (open het bestand direct in de browser), bewaart
profiel en planning in `localStorage`, en heeft geen koppeling met RDW of DigiD.
Hosted versie draait als statisch nginx-container op `monkey.syquens.com` achter
Traefik, met `Cache-Control: max-age=300`.

## Highlights

### Profiel
- **DET, massa, kentekensoort, MRB/kwartaal** als invoer.
- Afgeleide waarden zichtbaar gerekend: huidig schorsingstarief (hoog/laag),
  MRB per dag (kwartaalbedrag / 91,25), per maand, per jaar, en de datum
  waarop de camper overgaat naar het lage tarief (DET + 15 jaar).
- Persistent via `localStorage` — refresh of nieuwe sessie behoudt invoer.

### Vier rekenscenario's
1. **Vroegst ontschorsen** — gegeven een schorsingsdatum, wat is de eerste dag
   waarop ontschorsen mag (1 kalendermaand + 1 dag minimum).
2. **Tussen vakanties** — loont schorsen tussen twee vakantieperiodes, na aftrek
   van de juiste RDW-leges en met de 8-/91-dagen restitutiegrens en
   €5-niet-uitkeerbaar-grens correct verwerkt.
3. **Jaarplanning** — meerdere vakanties, netto-jaarbesparing.
4. **Lange termijn** — kostenoptimum bij meerjarige stilstand (1-jaar aanvraag
   vs. jaarverlengingen, met de juiste leges-mix per scenario).

### Regels & uitleg
- Toelichting op alle gehanteerde RDW-regels, 2026-tarieven en MRB-mechaniek.
- **Zelftest-blok** dat bij elke logica-aanpassing live de testcases doorrekent
  en groen/rood toont — een visuele regressietest in de UI.

### UX-fundament
- Dark mode via `prefers-color-scheme: dark` met eigen tokenset.
- Date-inputs in `dd/mm/jjjj` (geen native `<input type="date">`, voor
  consistente Nederlandse formattering).
- Tabs met `role="tablist"` / `aria-selected`, zelftest-output met `aria-live`.

## Privacy & sourcing
- **Privacy-guard hooks** (`hooks/pre-commit` + `hooks/pre-push`) scannen staged
  en gepushte content op persoonlijke identifiers en blokkeren bij een match.
  Patronen blokkeren onder andere e-mailadressen, GitHub-tokens, persoonlijke
  paden en specifieke voertuig-/persoon-hints. End-to-end geverifieerd op
  2026-05-03.
- Installer: `scripts/install-hooks.ps1` (Windows) / `scripts/install-hooks.sh`
  (POSIX) — zet `core.hooksPath` op `hooks/`.
- **MIT-licentie** + `.gitattributes` voor cross-platform line-endings.

## Domeinregels (peildatum 2026)
- RDW-minimum schorsing: 1 kalendermaand + 1 dag.
- Hoog tarief: M1 + < 15 jaar oud + ≤ 3500 kg. Anders laag tarief.
- Tariefovergang: DET + 15 jaar.
- 2026 RDW-leges: hoog €88,05 (1y aanvraag) + €29,10/jaar verlenging; laag €29,10 vlak.
- MRB per dag = kwartaalbedrag / 91,25.
- Restituties < €5 worden niet uitbetaald.

## Known Issues / Out of scope
- **BPM, fijnstoftoeslag en provinciale opcenten** worden niet apart gemodelleerd
  — de gebruiker geeft zelf het MRB-kwartaalbedrag op, waarin die opslagen al
  zitten. Geplande follow-up: kenteken-lookup via RDW open data + opcenten-tabel
  per provincie, zodat de tool zelfstandig de MRB kan berekenen.
- Geen RDW- of DigiD-integratie.
- Geen verzekerings- of APK-planning.

## Deployment notes
- Live host: monkey.syquens.com (statisch nginx-container).
- Source-of-truth voor stack-config (compose, Traefik labels, security headers,
  image pin) staat in **MyServers** (`E:\Dev\myservers\docs\monkey\schorsing.md`)
  — niet in deze repo.
- Routine deploy na `git push`:
  ```powershell
  ssh monkey-automation 'cd /srv/containers/schorsing/repo && git pull --ff-only && cp camper-schorsingscalculator.html ../site/index.html'
  ```
  Geen restart nodig; browsers zien de wijziging binnen 5 minuten (`max-age=300`).
- Smoke-test: `curl -sI https://mycamper.app/schorsing/` (200 + verwachte
  security headers).
